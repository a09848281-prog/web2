# FaceLab — 顔認識Webアプリ v1.0

GitHub Pages上で動く、ブラウザー内処理型の顔認識プロトタイプです。

## Web2本体との分離

- すべてのファイルを `face-recognition/` の中に配置しています。
- 既存のWeb2の `index.html`、CSS、JavaScript、Android、GAS、Actions設定は変更しません。
- Web2本体のURL: `https://a09848281-prog.github.io/web2/`
- FaceLabのURL: `https://a09848281-prog.github.io/web2/face-recognition/`

GitHub PagesでWeb2のデプロイが完了していれば、追加のサーバーやGAS設定なしでサブパスから開けます。

## 技術方式

1. face-api.js + Tiny Face Detectorで顔を検出
2. Face Landmark 68で顔の特徴点を抽出
3. Face Recognition Network（ニューラルネットワーク）で128次元特徴量を抽出
4. k近傍法に近い距離照合と登録サンプルの重心距離を組み合わせて照合
5. IndexedDBに顔特徴量・認証履歴を端末内保存

モデルとライブラリは初回利用時にCDNから読み込みます。外部AI API、APIキー、GAS、Firebaseは使用しません。推論・照合・データ保存はブラウザー内で行います。初回のモデル読込にはインターネット接続が必要です。

## 起動

1. GitHub Pagesのデプロイ完了を待つ
2. FaceLab URLをSafari / Chromeで開く
3. カメラを開始して権限を許可
4. 登録名を入力し、本人の同意チェックを入れる
5. 同じ人の顔特徴量を3〜5回追加して登録確定
6. カメラ映像内の顔をリアルタイム照合

## 保存とプライバシー

- 顔写真・映像は保存しません。
- 顔特徴量はブラウザーのIndexedDBに保存され、同じブラウザー・端末の中だけで利用できます。
- 認証履歴は最新10件です。
- 未登録者は画面表示のみで、自動登録・警告音はありません。
- JSONエクスポートには生体特徴量が含まれるため、取り扱いに注意してください。
- ブラウザーのサイトデータ削除、プライベートブラウズ、別端末では登録データを引き継げません。

## 重要な制限

- 一致スコアは距離から作った参考値であり、本人である確率ではありません。
- 顔認識の閾値は利用環境・照明・カメラにより調整が必要です。
- まばたき表示は簡易的な補助判定であり、写真・動画・マスク・ディープフェイクを防ぐ確実な生体検知ではありません。
- この試作を、入退室・決済・本人確認・監視対象の自動判定など重要な用途に単独で使用しないでください。
- Safari / iPadOSの機種やメモリ状況によっては処理速度が低下する場合があります。
