# GAS Setup
Create a Google Sheet, open Extensions > Apps Script, paste Code.gs, and run setupDatabase(). Run it again after v4.1 upgrades to create the Controllers sheet; existing data is preserved. Deploy as a Web App and set the resulting /exec URL in config.json. GAS + Sheets handle pairing, up to 3 per-browser controller tokens, and SDP/ICE signaling. Once DataChannel opens, live controls and telemetry use it directly. While fewer than 3 viewers are active, Android checks GAS at the selected 1–50 second interval only to discover additional offers; polling pauses at 3 active sessions. Do not share the spreadsheet. No audio/video is stored.
