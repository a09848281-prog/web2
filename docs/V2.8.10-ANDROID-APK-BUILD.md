# v2.8.10 Android APK build

## 対象
- ブランチ: `preview/v2.8.10-expressturn-stability`
- Android package ID: `jp.a09848281.remotecamera.v31`（既存のv2.8.xプレビュー版との更新互換性を維持）
- バージョン名: `2.8.10-preview`
- versionCode: `436`
- ビルド形式: Android debug APK（Playストア配布用の署名済みrelease APKではありません）

## APKの生成
このブランチへのpushで `.github/workflows/android-build.yml` が自動実行されます。手動実行する場合はGitHubの **Actions → Android APK Build (v2.8.10) → Run workflow** を使用します。

ワークフローはJava 17 / Gradle 8.9で、次の順番に検査・ビルドします。

1. JavaScriptとGASの構文検査
2. Node.jsの単体テスト
3. `scripts/check-project.mjs` のWeb・Android統合検査
4. `android/:app:assembleDebug` によるAPKビルド
5. `app-debug.apk` をActions artifactとして保存

成果物名: `remote-camera-web2-v2.8.10-expressturn-apk`

APKはActionsの該当実行ページ下部にある **Artifacts** から取得します。保存期間は14日です。APKそのものはソース管理に直接コミットしません。

## v2.8.10でのAPK側修正
- Androidアプリが取得する `config.json` の参照先をv2.8.10ブランチへ統一。
- APKのversionName、versionCode、ランチャー表示名を更新。
- GitHubから設定を取得できない場合、端末に保存済みの有効なGAS URLへフォールバック。無効なURLは使用しません。
- APKビルドのGradleエラーを調査しやすいよう、CIに `--stacktrace` を追加。
- これらの条件を `scripts/check-project.mjs` で継続検査。

## 重要な制約
- CIでAPKビルドが成功しても、Galaxy A22 5G（Android 13）とiPad間の実機WebRTC接続、画面消灯中の動作、TURNリレー成功を保証するものではありません。別端末・別回線での実機確認が必要です。
- Androidの強制停止、権限取り消し、OS再起動直後のカメラ・マイク自動起動はOS制限の影響を受けます。
- このAPKはdebugビルドです。Playストア公開向けの署名済みreleaseビルドではありません。
