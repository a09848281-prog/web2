# Web2 v2.8.7 – Bookmarklet overlay GAS bridge

## 変更内容
- v2.8.6 の安定ブランチは変更せず、専用ブランチで埋め込み表示向けGAS応答中継を追加。
- Web2 iframe は埋め込み元の HTTPS origin を GAS リクエストに含める。
- GAS は検証した origin を応答先に指定する。
- ブックマークレットは Google Apps Script から親ページへ届いた応答を Web2 iframe に中継する。
- Web2 は親ページから中継された応答を requestId と親 origin の両方で照合する。

## デプロイ手順
1. このブランチの `gas/Code.gs` 全文を既存のGASプロジェクトに貼り付ける。
2. 保存し、GASの「デプロイ」→「デプロイを管理」→既存ウェブアプリの編集から新しいバージョンを選んでデプロイする。
3. GitHub Actions の `Deploy PWA to GitHub Pages` を開き、ブランチ `preview/v2.8.7-embed-gas-bridge` を選択して実行する。
4. Pages のデプロイ完了後、ブックマークレットを登録する。

## 注意
- GAS の再デプロイが必要。Web側だけ更新しても旧GASコードのままでは中継できない。
- HTTPSの通常Webページで使用する。iOS Safariではカメラ・マイクの許可が埋め込み元サイトのPermissions Policyにも左右される。
- この修正はGAS応答の中継を対象とし、ブラウザーやサイト側がiframe自体を禁止している場合は表示できない。
- Android APK、v2.8.5安定プレビュー、v2.8.6安定プレビューには変更を加えない。
